# Hermes — Roadmap

The roadmap is the step-by-step learning path. Each phase is a self-contained
chunk that can be picked up independently and builds on the previous one. Phases
act as epics for the features in [../features.md](../features.md).

Every phase file follows the same shape:

- **Learning goals** — the concepts you should understand by the end.
- **Concepts to read** — short, focused background before building.
- **Steps** — the concrete, ordered work.
- **Definition of Done** — how you know the phase is complete.
- **Stretch** — optional challenges to go deeper.

Because learning is the priority, work through phases in order and prefer
understanding over speed. Pair-programming style: read the concepts, then build a
small step, then verify.
